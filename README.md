# Room booking system

A small full-stack room booking app using Express, MongoDB, Mongoose, React, and Tailwind CSS.

### Start both applications:

*Make sure to change the MONGO_URI environment variable with your own database url.*

```bash
npm run dev
```

The API runs at `http://localhost:5000` and the frontend at `http://localhost:5173`.

`npm install` can run in the root, `backend`, and `frontend` separately.
